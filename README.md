# Currículum · Ivanka Nikolova Gashurova

Landing del currículum de Ivanka (Vania) Nikolova Gashurova, administrativa y secretaria inmobiliaria trilingüe (ES · EN · BG) con marketing digital, contenidos e IA.

## Estructura

```
index.html                         Landing (responsive, lista para imprimir en A4)
assets/
  CV-Ivanka-Nikolova-Gashurova.pdf Currículum en PDF (botón «Descargar CV»)
  foto-ivanka-nikolova.jpg         Foto
  fonts/                           Fraunces y Manrope (woff2, sin dependencias externas)
```

## Publicación

- **Hosting propio:** sube el contenido del repositorio a la carpeta o subdominio que quieras.
- **GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / `(root)`.

La página lleva `noindex` para que no aparezca en buscadores; quita esa etiqueta del `<head>` si se quiere indexar.
